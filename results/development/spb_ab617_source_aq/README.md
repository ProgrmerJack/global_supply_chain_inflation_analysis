# WCWLB AB 617 source-oriented air-quality feasibility

The exact design was frozen and publicly approved at [OSF j6utx](https://osf.io/j6utx/) before any
station-specific chart response was opened. The registered window is 2020–2024.

`availability_screen.csv` applies the effect-blind rules to all 84 declared site/parameter/duration responses.
The official endpoint returned 1,392 values dated 16–23 July 2026 and no values in the registered window.
`feasibility_decision.json` therefore records `FAIL_FEASIBILITY`: 0 eligible primary sites and 0 concurrent
primary site-hours, versus requirements of 3 and 20,000.

No source coefficient, falsification result, bounded null, observed exposure result or health claim was
produced. The 259,749-row frozen AIS activity sensitivity panel remains a reusable physical input.
