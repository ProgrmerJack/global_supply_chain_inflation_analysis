# Invalidated first execution

The files in this directory are preserved as an immutable failed-execution receipt, not a scientific result.
The 23 July 2026 builder aligned string-indexed pivot series onto a datetime-indexed output frame. Every
ring/sector series therefore became missing even though the separately hash-verified GFW cache contained
positive in-ring activity. The all-`NaN` coefficients and `fail` label in `decision.json` are invalid.

`invalidation_receipt.json` records the exact error and artifact hashes. The correction may change only the
deterministic index alignment and add fail-closed integrity checks. It must be frozen and externally registered
before a rerun, and the rerun must write to a separate directory.
